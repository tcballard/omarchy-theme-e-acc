# e/acc — initial release draft

A dark Omarchy theme built around carbon black, reactor orange and warm white. A complete semantic palette lets Omarchy generate its native shell, terminal and editor colours.

Four wallpapers are included: Signal, Velocity, Icon Carbon and Hyperdrive. Signal is the lead wallpaper. Icon Carbon is a native 3840×2160 vector render; the other three are 1672×941 generated images.

Configuration and documentation are MIT-licensed. The original e/acc icon by Will DePue is CC0; generated artwork provenance is documented in CREDITS.md.

Status: release candidate preparation only. Live Omarchy acceptance, a real desktop preview, merge to main and final default-branch validation are pending. No release tag has been created.
